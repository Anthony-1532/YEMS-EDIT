# YEMS Administrative Presentation

This folder contains a static HTML presentation prepared from `../YEMS_PROJECT_REPORT.md`.

## Files

- `index.html` - full administrative slide deck.
- `styles.css` - visual theme, layout, responsive rules, and print styling.
- `script.js` - slide navigation, overview mode, counters, and animation behavior.

## How to View

Open `index.html` in a browser. Use the arrow keys, the on-screen buttons, or swipe on touch screens to move through the slides.

The deck uses GSAP and Animate.css from public CDNs for animation when available. CTA buttons use GSAP for entrance, hover, focus, and click feedback. Local CSS fallback animations keep the presentation usable if the CDN files do not load.
