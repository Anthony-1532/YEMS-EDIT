Project Overview

One platform for the entire school

YEMS is a school management system built for Yeshua High School. It handles academics, administration, finance, and communication in a single place.

Instead of scattered paperwork, separate spreadsheets, and disconnected tools — everything runs through one system that works on the school's own network. No internet required.

For leadership Complete oversight

See school activity, reports, and progress from one place.

For staff Less repetitive work

Manage lessons, assignments, results, and notices from one portal.

For students Everything in one place

Access notes, assignments, schedules, exams, and results.

Security

How school information is protected

Secure Sign-In

Every user logs in with a password. Sessions expire after 15 minutes and must be renewed.

Role-Based Access

Each person sees only what their role allows. A student cannot see admin settings.

Login Protection

5 wrong passwords locks the account for 15 minutes. Too many requests are slowed down.

Activity History

Every important action is recorded. Leadership can review who did what and when.

In place: Secure login, role-based access, login lockout, request limits, and full activity history.

How It Runs

Three computers, one system

The system is spread across three dedicated machines. Each one handles a specific job. This keeps things fast and allows 500 students to use it at the same time.

PC1 The Application — Linux

Runs the website and the system logic. This is what processes every request from users.

PC2 The Data Room — Windows

Holds the database, file storage, and background task queue. All school records live here.

PC3 The Front Desk — Windows

Receives all traffic from users and directs it to the right place. Keeps a log of every visit.

LAN Local Network Only

No internet needed. The system runs entirely inside the school. Users type a simple address.

How a request flows

A student opens the website → PC3 receives it → PC3 sends it to PC1 → PC1 checks PC2 for the right data → response goes back to the student. The whole thing happens in milliseconds.

Deployment Plan

Getting it running in 3 hours

The setup follows a step-by-step plan. Each step is checked before moving to the next. No guesswork.

Step 1 Connect the computers (15 min)

Make sure all three PCs can talk to each other on the school network.

Step 2 Set up the data room (75 min)

Install the database, file storage, and task queue on PC2. Lock it down.

Step 3 Set up the front desk (15 min)

Install the traffic director on PC3. Point it at PC1.

Step 4 Set up the application (30 min)

Connect PC1 to PC2. Start the website and system logic.

Step 5 Test everything (30 min)

Log in, create a user, upload a file, run a test exam. Confirm it all works.

Not Built Yet

What still needs work

The system is functional, but these features are either incomplete or not started. This is what the next phase addresses.

Auto-grading uses sample scores

The exam grading system runs, but it assigns random scores instead of checking answers. Real answer-checking logic is needed.

Device tracking not started

The technician portal cannot yet track which devices are connected to the system or monitor their status.

Alert system not started

There is no way to send alerts when something goes wrong — like a server going offline or a disk filling up.

No live messaging

Announcements work, but teachers and students cannot send messages to each other in real time.

No email service connected

The system can format emails, but it is not connected to a real email service to actually send them.

No automated backups

Database backups must be done manually. There is no automatic daily backup or restore testing.

Known Limits

Things to keep in mind

No mobile app yet

Students and teachers use it through a web browser on their phone. A dedicated app is planned for a later phase.

Reports are basic

The system can generate simple reports. More detailed analytics, charts, and custom report formats are needed.

Needs load testing

The system should be tested with 500 students using it at the same time before full school-wide rollout.

No external payment links

Fees are tracked manually. Online payment integration (bank transfer, card) is a future addition.
